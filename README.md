# Kang AC Balap Frontend

Frontend untuk Kang AC Balap - Layanan Service AC Sidoarjo. Dibangun dengan Vite + React + TypeScript + Tailwind CSS.

## Tech Stack

- **Vite** - Build tool
- **React 18** - UI Library
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling
- **Radix UI** - Komponen UI accessible
- **Recharts** - Charts/Analytics
- **Motion** - Animations
- **GSAP** - Advanced animations

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deploy ke Vercel

Project ini sudah dikonfigurasi untuk Vercel. достаточно:

1. Connect repository ini ke Vercel
2. Auto deploy akan berjalan
